Vidya-Vahini is an innovative GenAI-powered Android application developed to support rural students by improving daily transportation safety and accessibility. Many students in remote villages face difficulties due to irregular bus timings, lack of real-time updates, and unsafe travel conditions. This project aims to solve these challenges through smart technology and community-based communication.

The application provides real-time bus tracking using crowdsourced location updates from users traveling on the same route. Students can check live bus locations, estimated arrival times (ETA), and receive instant notifications about delays, route changes, or bus breakdowns. The app also includes a safe-reach alert system that allows students to notify parents or guardians when they arrive safely at school or home.

Vidya-Vahini uses artificial intelligence and location-based services to improve transportation reliability while reducing uncertainty for students and parents. The project focuses on enhancing safety, connectivity, and convenience for rural communities where advanced transport systems are often unavailable.

Key Features:

Real-time bus tracking
ETA and delay notifications
Crowdsourced bus location updates
Bus breakdown and emergency alerts
Safe-reach notifications for parents
User-friendly Android interface
Rural transportation support system

Technologies Used:

Android Studio
Java/Kotlin
Firebase Database
Google Maps API
GenAI integration
GPS and location services

This project demonstrates how AI and mobile technology can be used to create practical solutions for real-world rural transportation problems.
